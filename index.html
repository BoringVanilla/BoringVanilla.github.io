Configurar SRV no Cloudflare

Passo a passo para conectar seu jogo

Domínio Principal: jogo.com
IP do Servidor: 192.168.1.10
Porta do Jogo: 25565
1
Registro "A" (Aponta para o IP)
Crie um subdomínio interno para seu servidor. Não precisa ser complexo, use algo fácil.
Exemplo: srv.jogo.com -> 192.168.1.10
2
CNAME (Opcional)
Você pode criar um CNAME para o serviço apontar para o subdomínio criado acima.
Isso facilita o redirecionamento futuro. Se preferir, pule para o Passo 3.
Exemplo: gameserver.jogo.com -> srv.jogo.com
3
Registro SRV (O Serviço)
finalmente, configure o SRV para que quando as pessoas acessem o serviço, sejam direcionadas corretamente.
Exemplo: _minecraft._tcp.jogo.com -> srv.jogo.com:25565
Resumo para o Cloudflare
Copie cada linha gerada nos passos acima e cole no DNS do Cloudflare.
